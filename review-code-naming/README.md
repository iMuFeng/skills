# Code Naming Review Skill

An agent skill for reviewing filenames and source-code identifiers for clarity, precision, consistency, and ambiguity.

## Install

Install it from GitHub with the [`skills`](https://github.com/vercel-labs/skills) CLI:

```sh
npx skills add https://github.com/iMuFeng/skills/review-code-naming
```

The installer will prompt you to choose the agents and installation scope.

To install it globally for Codex without prompts:

```sh
npx skills add https://github.com/iMuFeng/skills/review-code-naming -g -a codex -y
```
